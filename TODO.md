# TODO — onetime: одноразовые ссылки для секретных данных

**Цель**: минималистичный веб-сайт (PHP + MariaDB + Nginx + PHP-FPM) для передачи
секретных данных и файлов по одноразовой ссылке. Ссылка выглядит как
`https://<домен>/<UUID>` — в будущем проект будет развёрнут на собственном
сабдомене.

**Как это работает**:
1. Отправитель вводит текст в `<textarea>`, прикладывает несколько файлов и жмёт
   «отправить» → получает ссылку с UUID и кнопку «скопировать».
2. Получатель по ссылке сначала видит подтверждение (чекбокс + «просмотреть»).
   После подтверждения показывается сообщение и вложения; в БД сохраняются
   время просмотра, IP и User-Agent, ссылка помечается просмотренной.
3. При повторном заходе — предупреждение, что ссылка уже просмотрена, с данными
   о том, кто смотрел (дата/время, IP, агент), и подсказкой связаться с
   отправителем, если это был не он.
4. Вложения отдаются отдельным URL `/<UUID>/f/<id>`, но только после того, как
   однократный просмотр уже потреблён (защита от предпросмотра ссылок
   мессенджерами и «заглядывания» в файлы).

**Ограничения проекта**:
- В репозитории **нет** данных инфраструктуры: хостнеймы, IP-адреса, пароли
  не допускаются (открытый проект).
- Коммит на каждый успешный шаг, Conventional Commits, пуш после каждого коммита.
- Дев-окружение: виртуальная машина на Alpine Linux (Nginx + PHP-FPM + MariaDB),
  доступ по ssh.
